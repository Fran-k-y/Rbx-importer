 # Voxenify RBXM Converter

A web-based Roblox file converter that turns `.rbxm / .rbxl` files into Lua output.

## Features
- Modern neon UI
- Drag & drop support
- File preview
- Animated background
- GitHub Pages ready

## Note
This is a **lite version**. Full Roblox decoding is limited in browser.
